# 공개 고용 통계

## 계층

- Bronze: 공식 CSV와 `source_files` 출처·체크섬. 원본은 검증된 최신 파일만 유지하는 기존 정책을 따릅니다.
- Silver: `companies`, `company_snapshots`. 월별 수정본 중 공개일·ID 기준 최신 자료를 선택합니다.
- Gold 기본: `employment_monthly_cube`. **자료월 × 업종 × 시도 × 가입자 규모**별 가산 가능한 합계입니다.
- Gold 제공: `public_monthly_statistics`는 전국·업종·지역별 월별 요약, `public_yearly_statistics`는 연간 요약입니다.
- `employment_cube_months`는 월별 원본 ID·생성 시각·큐브 행 수를 기록합니다. 일별 고용 자료는 생성하지 않습니다.

페이지는 제공용 테이블만 읽으며 원본 스냅샷 집계나 인덱스 생성은 하지 않습니다.
`/employment-trends`는 업종별 고용 변화 페이지입니다. 기본은 1년 전 대비 증가 인원순이며,
전월·3개월 전·1년 전 대비와 증가·감소, 인원·비율 정렬을 제공합니다.
최신 자료월과 정확한 비교월의 `public_monthly_statistics`만 조인하므로 별도 적재나 히스토리 스캔이 없습니다.
3개월 변화는 두 시점의 차이이며 이동평균·연속 증가가 아닙니다. 업종 변화이지 직업 인기·채용 수요 지표는 아닙니다.
양쪽 월에 자료가 있는 동일 업종명만 비교하며, 미분류·복수 업종은 제외합니다.
비율순은 양쪽 월 모두 가입자 1,000명 이상인 업종에 한정합니다. 인원순은 이 제한이 없고 비교월 0명은 비율 산출 불가로 표시합니다.
목록은 조건에 맞는 업종 중 상위 50개를 표시하며, 업종 상세의 월별 추이로 연결합니다.
회사 상세는 사이트맵에 포함하지 않습니다. `/sitemap.xml`에는 메인·통계 목록·최신 업종/지역별 통계 페이지만 제공합니다.
회사 상세 검색 노출 자체를 `noindex`로 차단하지는 않습니다. 관리자 화면의 기존 `noindex`는 유지합니다.

## 지표와 결측값

큐브에는 사업장 수, 가입자 수 합계, 가입자 수 미상 사업장 수, 신규취득·자격상실 합계와 각각의 결측 사업장 수,
급여 산출 대상 사업장 수·가입자 수·고지금액 합계를 저장합니다. 개인·사업장 ID는 저장하지 않습니다.
규모 코드는 `-1` 미상, `0` 0명, `1` 1~9명, `2` 10~49명, `3` 50~299명, `4` 300~999명, `5` 1,000명 이상입니다.
이는 법적 대기업·중소기업 구분이 아닙니다. 가입 상태 코드 `1`만 포함하며 명시적 일용 사업장은 적재 단계에서 제외됩니다.
사업장별 인원 합계이며, 여러 사업장에 가입한 개인의 중복을 제거한 인원 수는 아닙니다.

- 월별 가입자·사업장 수: 해당 월의 관측값. 월별 인원을 더해 연간 인원으로 표시하지 않습니다.
- 연평균 가입자·사업장 수: 해당 연도 자료가 있는 월을 분모로 계산합니다. 어떤 분류가 해당 월에 없으면 그 분류는 0으로 기여합니다.
- 마지막 월 인원: 해당 연도 전체 자료 중 마지막 자료월의 값. 12월 전이면 연말 확정값이 아닙니다.
- 연간 취득·상실: 자료가 있는 월의 누적값. 동일인이 여러 번 포함될 수 있어 고유 인원이 아닙니다.
- 월별 추정 연봉: 유효한 양수 가입자·고지금액의 `금액 합계 / 가입자 합계 / 해당 연도 보험료율 × 12`.
- 연간 추정 연봉: 월별 추정 연봉을 유효 가입자 수로 가중평균합니다. 분모는 가입자-월 수이며 개인의 연간 실제 급여가 아닙니다.
- 전월·전년 변화: 정확히 1개월·12개월 전 자료가 있을 때만 비교합니다. 회사 구성 변화도 포함합니다.

급여는 항상 **국민연금 기반 추정치**입니다. 값이 없는 경우 0원으로 만들지 않습니다.
인원·취득·상실 합계는 알려진 값만 더하고 결측 건수를 별도로 보관합니다.
관측월 누락은 차트에서 끊고, 연간 요약에는 자료월 수와 부분 집계 여부를 표시합니다.
미상·복수 분류는 전체 집계와 전체 목록에 포함하지만 상위 업종·지역 분포에서는 제외합니다.
원본의 제공 범위·분류 변경은 시계열 단절을 만들 수 있으므로 증감만으로 실제 고용 변화를 단정하지 않습니다.

업종은 당시 스냅샷의 명칭 기준입니다. 분류 체계나 명칭 변화가 있으므로 다른 명칭을 임의로 합치지 않습니다.
**과거 주소는 월별로 저장되지 않았습니다.** 지역은 집계 생성 시 보관된 `companies.address` 기준이며 실제 과거 소재지·이동을 의미하지 않습니다.
강원도·전라북도 등은 현재 시도 명칭으로 통합하며 미상 분류도 합계에서 누락하지 않습니다.

## 생성·복구

```sh
npm run stats:build-public            # 기존 과거 자료 최초 생성 / 미완료 월 재개
npm run stats:build-public -- --force # 모든 월 재생성: 분류 규칙·주소 변경 반영 시
```

공유 적재 잠금 아래 월 단위 트랜잭션으로 큐브·월별 요약·해당 연도 요약을 함께 갱신합니다.
완료된 동일 원본 월은 건너뛰며 중단된 월은 다음 실행에서 다시 생성합니다.
이후 CSV 적재·월별 통계 재생성 시 해당 월과 연도를 자동 갱신합니다. 원본 스냅샷이나 직접 SQL을 수정한 경우 `--force`로 복구합니다.
지역 주소가 바뀌어도 이미 생성한 과거 월은 자동 재분류하지 않습니다.

추가 조합 분석은 `getEmploymentBreakdown({ from, to, industry?, region?, sizeBand? })`로 큐브만 조회합니다.
분기·연도는 월 범위를 지정하고, 평균·비율은 금액·가입자 등 원시 합계로 계산합니다.
화면에서 자주 쓰는 새로운 조합은 별도 제공용 요약으로 구체화할 수 있습니다.
큐브는 합계·가중평균·구성비에 적합합니다. 중앙값·백분위·동일 사업장만의 고용 증감은
이 합계만으로 정확히 복원할 수 없으므로 원본 스냅샷 또는 별도 분포 집계가 필요합니다.
